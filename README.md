# 💎 UnionPB v3.8 Lux — Distributed Graphics Engine

**UnionPB (Union Pixel Battle)** — это высокопроизводительная асинхронная среда для коллективного графического проектирования в реальном времени. Сборка **v3.8 Lux** объединяет в себе математическую точность декартовой системы координат и промышленную стабильность хранения данных.

---

## 🚀 Основные возможности
* **Декартова система:** Координаты (0,0) расположены в левом нижнем углу холста для интуитивного проектирования.
* **Многопоточное рисование:** Использование `asyncio.Lock` и асинхронных вызовов предотвращает повреждение данных при одновременных запросах.
* **Persistence (Отказоустойчивость):** Реализация концепции **"Cloud-as-a-Storage"** — автоматическое восстановление холста из облачного бэкапа в Telegram при перезагрузке сервера.
* **Anti-Flood:** Встроенная логика защиты от спама (Middleware) и перегрузки графического ядра.

## 🛠 Технологический стек
* **Language:** Python 3.10+
* **API Framework:** `aiogram 3.x` (Asynchronous I/O)
* **Graphics Core:** `Pillow` (High-performance imaging)
* **Deployment:** Оптимизировано для `Render.com`

## 📐 Инженерная справка
В отличие от стандартных графических библиотек, движок UnionPB использует инвертированную математическую модель для удобства пользователя:
* **Точка отсчета (0,0):** Нижний левый угол.
* **Формула трансформации:** $$Y_{internal} = 1023 - Y_{user}$$
* **Масштабируемость:** Холст $1024 \times 1024$ (1,048,576 активных пикселей) обрабатывается в RAM с фоновой сериализацией.

## 🎮 Инструментарий
| Команда | Описание | Формат |
| :--- | :--- | :--- |
| `/add` | Установка пикселя (поддерживает списки через перенос строки) | `color x y` |
| `/line` | Отрисовка вектора между двумя точками | `color x1 y1 x2 y2` |
| `/circle` | Генерация идеальной окружности | `color x y r` |
| `/fill` | Заливка прямоугольной области | `color x1 y1 x2 y2` |
| `/point` | Инспекция цвета в конкретной точке | `x y` |
| `/zoom` | Оптическое увеличение выбранного сектора | `x y` |
| `/view` | Получение полного снимка полотна | - |

## 💾 Система бэкапов (Persistence Layer)
1. При каждом значимом изменении движок генерирует фоновую задачу для создания снимка холста.
2. Текущее состояние сохраняется в формате `.png` в приватный канал-хранилище под именем `matrix.png`.
3. Функция `load_last_canvas` при холодном старте сканирует историю канала для автоматической реконструкции состояния холста.

## 📦 Развертывание
1. Склонируйте репозиторий и убедитесь в наличии файлов `bot.py` и `COLORS.md`.
2. Создайте файл `.env` и укажите ваши данные. 
3. Настройте `startCommand: python main.py` в `render.yaml`.
